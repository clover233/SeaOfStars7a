## 定位与运行

weditor 连接仍报 Unsupported deviceId，已尝试 Dump Hierarchy。优先使用 uiautomator2 原生节点的
文本、描述、资源 ID 和边界；正文不导出时沿用本地 Vision OCR。纯图标与弹窗 X 按核对过的屏幕比例换算。
没有固定像素点击。底部导航优先点击原生可点击父控件，避免文字节点落在点击区域边缘。
股票搜索使用 `new_title_search` / “股票搜索”，加删自选使用 `ll_add_remove_zixuan`，状态读取 `tv_add_remove_zixuan`。
UC 搜索按钮资源 ID 为 `cancel`，必须同时校验文字“搜索”，不会将它当作取消按钮。

`observed_apps_common.py` 复用现有逐步 Perfetto、截图与 JSON 结果逻辑。广播输入法在采集前准备，结束时恢复原输入法。
广告、通知引导和退出提示先关闭；输入法协议或系统权限只使用明确的拒绝/取消入口，不接受协议或扩大权限。
UC 退出提示点取消，不勾选清除浏览记录。

## 适配与状态保护

- 同花顺先核对“格力电器”详情及按钮状态。如果它原已在自选，添加和删除步骤跳过，保留原有自选。
  只删除本次确认新增的这一只股票；异常清理也依据同样归属条件恢复。不进入下单或开户流程。
- 12306 使用首页现有出发地、目的地和日期，不写死日期、不预订车票或酒店。
  排序按钮已点击并保存截图，但当前控件未导出排序方向，三项排序记 `ADAPTED`。
  需登录的页面只验证到登录入口，不输入账号。
- 当前 UC 部分频道会跳转独立页面，五次左右滑改为横滑顶部频道栏浏览入口，记 `ADAPTED`。
  体育/推荐频道未导出选中状态时，记录点击和截图，不虚报已读取选中状态。
  “搜索发现”由当前“资讯热搜榜”替代；从结果页返回时，经首页重新打开编辑页。
  搜索结果可能包含内联广告，只滚动浏览，不点击下载、安装或购买。
- 缺失入口、内容加载失败与依赖步骤均有具体 `SKIP` 原因；意外异常记 `FAIL`。
