实机定位环境：2026-10-15，小米M154FF、Android 17，相册5.4.2.10-0907-cn。尝试weditor连接后报Unsupported deviceId，继续尝试Dump Hierarchy，再使用uiautomator2层级和截图核对。Compose控件主要通过content-desc定位；点击取实时bounds中心；主屏通过input -d 0注入。照片主页、全部照片及视频列表的缩略图没有独立语义节点，先检查页面标识、恢复列表顶部，再从截图识别首行缩略图色块，按识别区域比例点击；适配下拉时统计/云同步提示导致的网格位置变化。选择器有独立媒体节点，勾选圆圈按该缩略图bounds的右下角比例定位。

适配说明：
- 本版双指缩放连续改变缩略图密度，未提供可读取的日/月/年标签。执行两次捏合、两次捏开，共5轮；每轮截图。此步标记ADAPTED，不把日月年层级切换当作已断言通过。
- 大图没有底部预览条，对应的右滑3次、左滑3次改为大图区域滑动，标记ADAPTED。
- 本版日视图没有可定位的拖动滚动条，第6步标记SKIP并注明原因，抛滑与跟手滑分别执行150ms、900ms手势。
- “图片”入口使用影集页的“全部照片”。选择器使用“照片/影集”分栏，其中照片列表同时包含照片和视频，因此浏览该列表并切换影集分栏，标记ADAPTED。
