# 微信动态性能用例 0090—0130

按《动态性能模型测试用例7.xlsx》第一张表 1748—1817 行编写，保留全部 70 步及原始顺序。
五个类继承 `weixin_extended.py`，继续复用 `weixin_common.py` 的逐步 Perfetto 采集、截图和结果记录。
`main.py` 已导入这五个类，沿用现有运行队列。

| 0090 | 12 | 华为手机搜索、扫一扫、收付款、二维码收款 |

## 定位

本机 weditor 连接报 `Unsupported deviceId: Android:cff0cbff`；尝试 Dump Hierarchy 后，
使用 uiautomator2 层级与实机截图核对。正文不导出有效节点时使用已有的本地 Vision OCR。
文字以当前识别框中心定位；搜索图标、首张直播画面等无文字入口使用已核对的屏幕比例。
所有点击/滑动在运行时按 `window_size()` 换算，没有写死工程点击像素。
Android 17 对短促点击偶有过滤，新用例用鼠标源原地按住 200ms 注入点击。

“我”和“发现”各自校验页面内容。返回首页时关闭加号菜单；退出本用例打开的直播时关闭自动生成的
浮窗并确认消失，避免遮住后续服务、转账说明或公众号入口。浮窗优先使用原生“关闭”控件；
子控件未导出时，按浮窗自身边界比例换算 X 的位置。

## 适配与边界

- 0090 未提供指定二维码，以进入扫一扫取景页并停留替代扫描结果，记 `ADAPTED`。
  当前收付款窗口启用 `SECURE`，截图正文为空、控件树没有可用节点；收付款校验与二维码收款两步记 `SKIP`。
- 0100 当前游戏默认显示圈子信息流，以该页替代旧版本首页，记 `ADAPTED`。
- 0110 按当前城市选择列表第一项电费单位；若名称不是电网公司，记录实际替代项。
- 0120 按用户最新要求，将表中的“测试账号”替换为已核对的置顶会话“测试”。
  红包仅打开后返回；转账仅输入说明“修改”、确认说明、返回，不输入金额，不提交交易。
- 0130 当前央视新闻使用“打卡笔记”替代“文博日历”；夜读若只显示其他主题而没有夜读详情，记 `SKIP`。
  首页“公众号”替代旧版“订阅号”。订阅信息流未出现腾讯新闻时，从已关注公众号列表进入同一账号，记 `ADAPTED`。
- 不输入充值号码、缴费户号，不选择金额，不点击支付/充值/缴费提交按钮。协议确认或账号/网络限制记具体 `SKIP`。

正式运行每一步保存 `step_results.json`，区分 `PASS / ADAPTED / SKIP / FAIL`，
记录定位方式与 trace 导出状态。功能缺失会使依赖步骤一并跳过，返回步骤继续执行。
实机交互验证报告和每步 PNG/XML 位于 `Result/weixin_0090_0130_validation/`。
实机与 OCR 校验有额外耗时，性能分析应结合 trace 中实际交互区间。
